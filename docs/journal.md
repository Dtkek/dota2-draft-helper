# Журнал сессий

Общая память для Claude Code на Mac и ПК. Каждая сессия при старте читает
последнюю запись (это делает хук автоматически), а в конце работы дописывает
свою — **новые записи снизу**, коммит и push. Формат записи:

```
## ДАТА · машина (mac / pc) · коротко о чём сессия

**Сделано:** что изменилось и где (файлы, коммиты).
**Проверено:** что реально запускалось и что показало.
**Открыто:** что не доделано, что сломано, какие гипотезы.
**Следующий шаг:** одна строка — с чего начинать следующей сессии.
```

Запись — не отчёт и не пересказ диалога: только то, что нужно, чтобы
продолжить с другой машины. Подробности — в коммитах и `docs/handoff_*.md`.
