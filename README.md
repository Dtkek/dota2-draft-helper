# Pickline

Локальное приложение для Dota 2, которое подсказывает, кого брать против
вражеского драфта. Считает преимущество по матчапам со сглаживанием под размер выборки,
учитывает синергию с союзниками, базовую силу героя в вашем ранге, турнирную
мету и вашу личную статистику — и показывает, из чего сложился каждый балл.

Умеет само узнавать героев на экране драфта, получать своего героя от игры
через Game State Integration и показывать сборку по про-матчам. В игру не
вмешивается: не читает память, ничего не внедряет, не нажимает за вас.

**Windows, без установки:** скачать
[pickline.exe](https://github.com/Dtkek/pickline/releases/download/latest/pickline.exe)
и запустить. Один файл, Python и распаковка не нужны.

**Из исходников (macOS, Linux, Windows):** `python3 app/server.py` —
стандартной библиотеки Python 3 достаточно; пакеты нужны только для чтения
экрана и собственного окна.

Подробно — что умеет, откуда данные, как считается оценка, что делать,
если не работает: [app/README.md](app/README.md).

Данные: [OpenDota](https://www.opendota.com) и [STRATZ](https://stratz.com)
(Powered by STRATZ). Лицензия — MIT.
